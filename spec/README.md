# Accountable Replicated Saga (ARS) — TLA+ models v4

A protocol for multi-step workflows that span mutually distrusting
organizations, such as AI agents from different companies transacting with each other.
Any number of orgs may be Byzantine, and so may the log operator. ARS doesn't
try to *prevent* misbehavior. It guarantees:

- **Accountability.** An honest party is never blamed. A provable failure
  is pinned on one Byzantine party by public signed evidence; an unprovable
  one narrows to a pair that includes a Byzantine party.
- **Termination.** No party can stall a saga.
- **Consequences.** Blamed parties lose a posted bond. An unresolved dispute
  freezes both bonds and holds the saga, so it moves no money either way.

Two specs:

| Spec | What it models |
|---|---|
| `AccountableSaga.tla` | The protocol: DAG-shaped sagas, replicated plans, owner/beneficiary side effects, trusted oracles, compensation, pivot steps, holds, bond settlement, and a log operator that may censor entries. Assumes the operator shows every org the same log. |
| `LogFork.tla` | Discharges that assumption. A log operator that shows orgs different histories is caught by gossip of signed heads, and in-flight sagas converge before finality. |

| `MCCheckout.tla` | A concrete instance: an AI shopping agent buying from a merchant's agent, with a payment processor as oracle and a carrier. |
| `AccountableSagaProofs.tla` | A TLAPS proof that honest orgs are never blamed, for **any** number of orgs, steps and Byzantine parties, with an honest or a censoring log operator. Its step lemmas are generated by `gen_proofs.py`. |

Earlier versions are kept in `history/v1`, `history/v2`, `history/v3` and `history/v3.1`. The mutated specs used for mutation testing are in `mutations/` (run each with `S.cfg`).

## v4: censorship, irreversible steps, disputes without an oracle

A review against the Go prototype found three ways an honest party could
still lose its bond or its money, each outside what v3.1 modelled:

| Gap in v3.1 | Failure | v4 fix |
|---|---|---|
| The log operator timestamps every entry, and v3.1 assumed it includes honest ones on time | An operator that drops an honest vote makes that org a "silent voter": slashed | Every append returns a **signed receipt**. A refused entry is gossiped as a signed **claim**, which discharges the duty. A claim backed by a receipt the log didn't honor blames the operator alone; a plain refusal is an unresolved dispute between the org and the operator (bond frozen, not slashed). |
| Every effect was assumed undoable | An honest carrier that delivered, then saw the step abort, owed an undo it couldn't perform: slashed for default | **Pivot** steps: the last step, which everything else leads to. Once it commits nothing can abort; if it aborts, its owner owes no undo. |
| A dispute with no oracle unwound the saga | A buyer who falsely disputes delivery got a refund and kept the parcel, at the cost of a frozen bond | The saga **holds**: the step ends `disputed`, nothing further commits or unwinds, and both bonds are frozen for outside resolution. |

Duties and evidence are now judged on everything a party **signed**, on the
log or in a claim. Outcomes (does a plan pass, does an effect commit) are
still decided by the log alone. A Byzantine org can falsely claim
censorship to turn its own slash for silence into a freeze, the same
weakness pair disputes already have.

## v3.1: split response windows

The Go prototype's randomized test found a gap between the model and
anything you could actually implement. With one effect window, a Byzantine owner can
attest at the last instant. An honest beneficiary then has no time to
answer and is accused of being a *silent beneficiary*. v3 didn't show this
because its deadline actions *waited* for honest orgs, and no fixed-length
deadline can do that.

The fix is to never ask a party to respond inside the same window that its
counterparty controls:

- **Effect phase** = `effect` (the owner attests) + `respond` (the beneficiary confirms or disputes)
- **Compensation** = `open` (undos and receipts) + `respond` (beneficiaries check undos)
- **Oracle steps:** the beneficiary has no duty at all, because the oracle decides.

Every deadline guard now waits only for honest actions that were already
possible when its window opened, which a fixed-length window can guarantee.

## What changed in v3

| Open in v2 | v3 fix |
|---|---|
| Log equivocation assumed away | **Gossiped signed heads** (`LogFork.tla`). Two heads for one phase = fork proof against the operator. A withheld head = local timeout + gossiped claim. Any conflict before finality triggers **abort dominance**: everyone compensates. After finality, outcomes never change. |
| Disputes resolved externally | **Trusted per-step oracles.** On steps with an oracle (e.g. a payment processor's signed webhook), the oracle's report decides. False attestations and false disputes become **individual** evidence instead of a disputed pair. |
| No consequences | **Bonds.** At settlement, accused orgs are slashed, orgs in an unresolved dispute are frozen, everyone else gets their bond back. |
| Linear sagas only | **DAG sagas.** Steps open when their dependencies commit and run in parallel. Any abort cancels everything in flight. Compensation runs in reverse topological order. |

## Protocol (per step)

1. **Opens** once every step in `Deps[s]` has committed.
2. **Plan.** Every org re-executes the deterministic plan and logs a signed
   vote: the result, or `ABORT` if execution fails. At the deadline, the plan
   passes only if all votes match and nothing conflicts.
3. **Effect.** The **owner** performs the side effect and attests to it. On oracle
   steps the **oracle's** report decides. Otherwise the **beneficiary**
   confirms or disputes it. Deadline: commit, abort, or (a dispute with no
   oracle) hold.
4. **Any abort aborts the saga.** Steps still in flight are cancelled. During the
   compensation window, orgs undo committed steps in reverse topological order and
   log receipts. Owners undo attested effects, including those of cancelled
   steps, except on a pivot. The beneficiary or oracle checks each undo.
5. **A hold ends the saga where it is.** Steps in flight are cancelled and nothing
   is undone.
6. **Settlement** on bonds: slash, freeze or return.

Every entry is submitted to the log, which returns a signed receipt. If the
log refuses it, or later doesn't hold it, the submitter gossips a signed claim.

### Evidence

| Evidence | Blames | Proof |
|---|---|---|
| Equivocation | one org | Two contradicting signed entries |
| Wrong result / unjustified veto | one org | Re-execution contradicts the vote |
| Silent voter, owner or beneficiary | one org | Deadline passed without its entry, logged or claimed |
| False attestation / false undo | one org | Oracle never saw the effect or undo |
| False dispute | one org | Oracle saw what it disputed |
| Default | one org | Compensation deadline passed with an obligation unmet |
| Dispute (no oracle) | a pair | Beneficiary contradicts owner, and nothing settles it |
| Censorship claim | an org and the log operator | The org says the log refused its signed entry; nobody can tell who lies |
| Broken promise | log operator | A signed receipt for an entry the log doesn't hold |
| Log fork | log operator | Two signed heads for one phase |

## Properties

**`AccountableSaga.tla`**

| Property | Meaning |
|---|---|
| `Accuracy` | No individual evidence names an honest org |
| `DisputeAccuracy` | Every unresolved dispute involves a Byzantine party (org or operator) |
| `OperatorAccuracy` | Only a Byzantine operator breaks a signed receipt |
| `AbortAccountability` | Every abort of a step that should have succeeded is attributable |
| `OracleAbortsNamed` | On oracle steps, blame is individual, never an owner/beneficiary pair; only a censoring operator can leave such an abort unnamed |
| `Validity` | A committed plan result is the correct, re-executable one |
| `EffectIntegrity` | A committed effect really happened (honest beneficiary or oracle) |
| `EffectsUndoneOrBlamed` | After compensation, every effect owed an undo is undone or someone is blamed |
| `HonestReceiptsTruthful`, `HonestUndoOkTruthful` | Honest attestations never lie |
| `DepOrder` | A step opens only after all its dependencies committed |
| `CompensationReverseTopo` | A step is undone only after everything that depended on it |
| `HonestNeverSlashed` | Honest bonds are never slashed |
| `FrozenOnlyWithByz` | An honest bond is frozen only in a dispute with a Byzantine party |
| `SettlementStable` | No evidence appears after settlement; slashed ⇔ accused |
| `NoUnwindOnDispute` | A disputed effect never triggers compensation; it holds instead |
| `HoldUnwindsNothing` | A held saga undoes nothing |
| `PivotIsFinal` | Once a pivot commits, every step has committed |
| `Termination` | Every saga finishes **and settles**, even with silent Byzantine orgs and a censoring operator |

**`LogFork.tla`**

| Property | Meaning |
|---|---|
| `ForkAccuracy` | An honest operator never produces a fork proof |
| `DivergenceDetectable` | If two orgs acted on different outcomes for a phase, their combined material shows the conflict |
| `FinalAgreement` | After finality, every org reached the same outcome |
| `FinalClean` | A finally aborted saga is fully compensated |
| `FinalStable` | After finality, nothing an operator signs changes any outcome |
| `Termination` | Finality is always reached, even with a Byzantine operator |

## Model-checking results

TLC, v4 spec. "Holds" = every invariant listed above, plus `Termination` where marked.

Configs with a Byzantine org or a censoring operator use the state
constraint `OneClaim` (at most one censorship claim, true or false, per
behaviour; `TwoClaims` where noted). Without it a Byzantine party can log
or claim each of its entries, which multiplies the state space. The TLAPS
proof of `Accuracy` has no such bound.

| Config | Model | Result | Distinct states |
|---|---|---|---|
| `FullHonest` | diamond, no Byzantine orgs | holds + termination | 1,995 |
| `Full1Byz` | diamond (1 ∥ 2 → 3), oracle on Byzantine beneficiary's step | holds + termination | 4,147,232 |
| `CensorByzOp` | diamond, censoring operator, honest orgs, one claim | holds + termination | 36,831 |
| `CensorByzOp2` | as above, two claims | holds (safety) | 281,879 |
| `InvCensor` | inductive invariant `Inv`, censoring operator | holds | 36,831 |
| `Checkout_Honest` | checkout, ship is the pivot | holds + termination | 7,986 |
| `LogForkByzOp` / `LogForkHonestOp` | log operator lying / honest | holds + termination + `FinalStable` (unchanged since v3) | 44,302 / 95 |

**Witnesses** (all reachable, so no pass is vacuous): full completion (diamond and
checkout), parallel steps, an attested effect of a cancelled step being undone, the
oracle catching a liar, an unresolved dispute, slashing, freezing, a held saga, a
censorship claim, a broken receipt, and an aborted pivot whose effect stays done;
for logs: a fork, a fork reopening a "done" saga before finality, a fork after
finality (with no effect), withholding.

**Mutations** show the properties actually catch bugs. Each one removes one
protocol rule, and TLC finds the expected violation (`make tlc-mutations`).
Mutations 1–3 were caught on v3.1; all six are regenerated for v4 but were
not re-run (see below):

| Mutation | Expected violation |
|---|---|
| `mut1`: effect deadline doesn't wait for the oracle | `Accuracy`: an honest owner is accused of a false attestation |
| `mut2`: settle before the saga finishes | `SettlementStable`: evidence appears after bonds are settled |
| `mut3`: compensate in any order (chain DAG) | `CompensationReverseTopo` |
| `mut4`: a pivot still owes an undo | `Accuracy`: an honest pivot owner defaults on an undo it can't perform |
| `mut5`: a dispute unwinds the saga | `NoUnwindOnDispute` |
| `mut6`: silence ignores censorship claims | `Accuracy`: a censored honest org is a "silent voter" |
| Finalize with an unresolved log conflict (`LogFork.tla`) | `FinalAgreement` |

## Proof: honest orgs are never blamed, at any size

TLC only checks small instances. `AccountableSagaProofs.tla` is a
machine-checked TLAPS proof of

```
THEOREM SpecAccuracy == Spec => []Accuracy
```

It holds for **any** number of orgs, Byzantine orgs, steps, plan values and any
DAG, with an honest or a censoring log operator. TLAPS 1.6.0-pre proves all
1,636 obligations, with no omitted steps (on Apple silicon, the release's
bundled x86 `z3` must be replaced with a native one, and `--stretch` helps on
a busy machine).

The proof uses an inductive invariant with twelve clauses, each closing one way
an honest org could otherwise be named by evidence. "Filed" means signed, on
the log or in a censorship claim:

| Clause | Says |
|---|---|
| I1 | Honest votes, logged or claimed, always equal the correct re-execution |
| I2 | Honest beneficiaries never contradict themselves, and never dispute on oracle steps |
| I3 | Once a plan closes, every honest org has filed a vote |
| I4 | Once the owner window closes, an honest owner has filed its attestation |
| I5 | Once the effect phase ends, an honest beneficiary has filed its answer |
| I6 | An honest owner only attests effects it really performed |
| I7 | The oracle filed a report of every real effect before its phase ended |
| I8 | Nothing is undone unless compensation started (not before, not in a hold) |
| I9 | Compensation or a hold starts only with no step in flight |
| I10 | An honest owner's undo attestation is true |
| I11 | After the undo window, honest receipts and undos are all filed |
| I12 | After compensation, honest undo checks and oracle refund reports are all filed |

Structure:
- `InitInv`: the invariant holds initially.
- `Step_<Action>`: one lemma per action shows it preserves every clause.
  These are generated by `gen_proofs.py`; rerun it after changing an action.
- `Inductive` combines the step lemmas.
- `InvAccuracy` shows that none of the nine evidence predicates can name an honest org.
- `SpecAccuracy` closes with temporal logic.

Before the proof was attempted, TLC confirmed the invariant on 510k reachable states (`MCInv.tla`, `Inv1Byz.cfg`; TLC needs `TLAPS.tla` from your tlapm install on its library path, e.g. `-DTLA-Library=<tlapm>/lib/tlapm/stdlib`).

```sh
tlapm -I <tlapm>/lib/tlapm/stdlib AccountableSagaProofs.tla
```

`FinalAgreement` (in `LogFork.tla`) is still TLC-checked only. Proving it
needs reasoning about gossip convergence, which is a larger invariant.

## Assumptions

1. **Partial synchrony.** Deadlines are long enough for honest orgs, the
   oracle and one full gossip round. The mutations show this is
   load-bearing: break it and honest parties get blamed.
2. **Deterministic plans.** Only the plan half of a step is re-executed.
3. **An observer per effect.** A beneficiary that can see the effect, or a
   trusted oracle. Steps with neither rest on the owner's signed word.
4. **Trusted oracles are trusted.** A lying oracle is outside the guarantee.
   Use oracles that are already the source of truth, such as the payment processor.
5. **Censorship by the log operator is detectable, not provable,** unless it
   signed a receipt. A refused entry causes an abort and a dispute between the
   refused party and the operator, never blame. A dropped entry the operator
   signed for, and equivocation, are provable.
6. **Claims reach every org before finality,** the same gossip assumption as
   `LogFork.tla`. A claim's window is checked against the time its signer
   states, so a Byzantine org can file a false or backdated claim, but only to
   turn its own slash for silence into a freeze.
7. **Irreversible effects are pivots,** and a saga has at most one: the last step.
8. **Bond sizing is economic, not formal.** Slashing deters only when the bond is at least
   what a party could gain by misbehaving in one saga. A frozen bond needs an
   external resolution path.
